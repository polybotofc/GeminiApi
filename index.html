Documentation Preview

Contoh integrasi API dalam berbagai bahasa dan framework.

JavaScript — Fetch API 
fetch("https://poly-md.my.id/response?message=halo")
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error("Error:", err));
JavaScript — Axios 
import axios from 'axios';

axios.get("https://poly-md.my.id/response?message=halo")
  .then(res => console.log(res.data))
  .catch(err => console.error("Error:", err));
JavaScript — TikTok Downloader 
// TikTok Downloader API
const videoUrl = "https://www.tiktok.com/@user/video/123456789";

fetch(`https://poly-md.my.id/tiktok?url=${videoUrl}`)
  .then(res => res.json())
  .then(data => {
    console.log("Video URL:", data.result.videoUrl);
    console.log("No Watermark:", data.result.noWatermark);
  });

Frequently Asked Questions

Cukup lakukan HTTP GET request ke endpoint yang tersedia. Contoh: GET https://poly-md.my.id/response?message=halo. Response akan dikembalikan dalam format JSON.

Saat ini beberapa endpoint tersedia secara gratis tanpa API key. Untuk akses Pro dan Enterprise dengan fitur lebih lengkap, hubungi kami melalui halaman Contact.

Free plan: 1.000 requests/day. Pro plan: 100.000 requests/day. Enterprise: unlimited. TikTok Downloader API memiliki limit 10.000 requests/day untuk semua plan.

Ya, setiap API memiliki dokumentasi lengkap dengan contoh kode dalam berbagai bahasa (JavaScript, Python, PHP, dll.), schema request/response, dan error code reference.

Semua API mengembalikan response dalam format JSON standar dengan field status, code, dan result. Lihat tab Documentation Preview untuk contoh response lengkap.
